What it is

Familiar on purpose.

ImagineOS is a Linux distribution focused on recreating recognizable Windows-era desktop experiences. Each edition changes the visual experience while keeping the same Linux foundation underneath.

It is not Windows, does not include Microsoft Windows, and is not affiliated with Microsoft.
